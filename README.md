# 星绘工坊 · StarCanvas

一款**安卓端的零代码视觉小说 / Galgame 编辑器**：在手机上写剧情、放立绘、配音乐、做分支，然后直接在同一個 APP 里点开试玩。不需要导出打包，工程像剪映草稿一样保存在手机本地。

> 轻量 2D 图文对话工具，没有 3D、没有复杂特效，千元机也能流畅跑。

## 1. 它有什么

### 编辑器（4 个固定模块）

| 模块 | 能做什么 |
| --- | --- |
| **开始** | 作品标题、封面图（自动裁成 16:9）、开场 BGM |
| **剧情** | 随时切换背景；多个角色显示 / 隐藏 / 更换立绘；上传道具小图；角色和道具共用 **最左 / 左 / 右 / 最右** 4 个点位；每个节点可设置 BGM（保持 / 播放 / 停止）和音效 |
| **对话** | 输入台词（播放时逐字显示）；最多 4 个分支选项 A/B/C/D，每个选项下拉选择要跳转的剧情节点；没有分支时可以指定「点击继续到哪个节点」或直接进入结局 |
| **结束** | 结局画面（16:9）、收尾音频、结局文字 |

- 顶部固定 16:9 舞台预览，改哪里看哪里。
- 节点用横向卡片条管理：新增、复制、重命名、删除、从当前节点开始试玩。
- 自动保存（停止输入约 0.6 秒后写入），切后台 / 返回也会保存。

### 播放器

- 横屏沉浸式全屏。
- 打字机逐字动画，点一下立即显示全句；再点进入下一段。
- 背景、四个点位的角色 / 道具、BGM / 音效按节点切换。
- A/B/C/D 选项按钮，点选后跳转对应剧情。
- 结局画面 + 收尾音频。
- **存档 / 读档**：每个作品 6 个存档位，带当前画面缩略图；存档存在各自作品目录里，作品之间完全隔离，不会串档。

### 素材处理（手机端自动完成）

- 图片上传后进入裁切页：拖动 + 双指缩放 + 双击复位；背景锁定 16:9，不会拉伸变形。
- 角色立绘、道具图自动裁掉透明边，保留原比例，不强制正方形。
- 背景压成 **1280×720 JPEG**；立绘最长边 **1000 PNG**；道具 **360 PNG**。
- WAV 统一转 **22050Hz / 单声道 / 16bit**；mp3 / ogg / m4a 本身已压缩，原样保存不二次转码。
- 像素处理放在 isolate 里跑，低端机不会卡住界面。

### 数据与清理

所有内容都在 APP 私有目录中（不需要存储权限）：

```
Android/data/com.hajibang.starcanvas/files/   ← 系统管理，卸载即清空
└── starcanvas/
    └── projects/
        └── <作品ID>/
            ├── project.json     ← 标题、节点、分支、素材索引
            ├── assets/          ← 背景 / 立绘 / 道具 / BGM / 音效
            └── saves/           ← slot_1.json ... slot_6.json + 缩略图
```

删除作品时会**递归删除整个作品目录**（配置 + 全部素材 + 全部存档），不会越用越占空间。替换素材后也可以清理没有被引用的孤儿文件。

## 2. 快速开始

### 直接装 APK

构建产物在：

```
build/app/outputs/flutter-apk/app-release.apk
```

把这个文件发到安卓手机（微信 / QQ / 数据线都行），点开安装，允许「安装未知来源应用」即可。首次启动会自动生成一个叫《星海之约》的示例作品，直接点试玩就能看到完整效果。

### 从源码构建

需要 Flutter 3.47+、Android SDK（platform 36、build-tools 36）和 JDK 17，**不需要安装 NDK**。

```bash
git clone https://github.com/Z-DFFDGH/starcanvas.git
```

```bash
cd starcanvas
flutter pub get
flutter build apk --release
```

Windows PowerShell 同样：

```powershell
cd starcanvas
flutter pub get
flutter build apk --release
```

> 当前 release 包使用 Flutter 默认的 debug 签名，自己装着玩没问题；要上架应用商店需要自己生成 keystore 并在 `android/app/build.gradle.kts` 里配置 signingConfig。

### 开发调试

```bash
flutter analyze          # 静态检查
flutter test             # 单元测试（模型 / 音频压缩 / 示例工程）
flutter run              # 连真机或模拟器
```

本项目在 Flutter 3.47.9 / Dart 3.13.7 上验证通过。

## 3. 上手流程

1. 首页点右下角 **新建作品**，输入名字。
2. 在 **开始** 模块设置标题、封面、开场 BGM。
3. 在 **剧情** 模块选背景、上传角色 / 道具并摆到四个点位。
4. 在 **对话** 模块写台词；想分支就填 A/B/C/D 并在右侧下拉选择目标节点。
5. 点节点条上的 **+** 新增下一段剧情；节点之间的跳转就是一条条「线」。
6. 在 **结束** 模块设置结局画面和收尾音频。
7. 点右上角 ▶ 直接在 APP 里试玩；试玩界面里可以存档、读档、重开。
8. 返回首页，作品卡片上也能直接点试玩。

### 分支是怎么连的

- 节点没有选项、且设置了「点击画面继续到」→ 点击后去目标节点。
- 节点有任意一个非空选项 → 必须点选项，自动跳转不会生效（避免误触）。
- 选项的目标选「进入结局」或留空 → 点了就进结局。
- 节点没有下一段、也没有选项 → 点击后进入结局。

## 4. 代码结构

```
lib/
├── main.dart                  # 入口、主题、中文本地化
├── core/theme.dart            # 深色主题与配色
├── models/models.dart         # 工程 / 节点 / 素材 / 存档数据模型
├── data/
│   ├── app_paths.dart         # 私有目录路径
│   ├── project_store.dart     # 工程与素材读写、删除、孤儿清理
│   ├── save_store.dart        # 每个工程独立的 6 个存档位
│   └── project_repo.dart      # 作品列表状态（ChangeNotifier）
├── services/
│   ├── asset_service.dart     # 选图 / 裁切 / 压缩 / 音频试听
│   ├── audio_compress.dart    # WAV → 22050Hz 单声道
│   └── sample_project.dart    # 首次启动生成的示例工程
└── ui/
    ├── home_page.dart         # 作品库
    ├── editor_page.dart       # 四模块编辑器
    ├── player_page.dart       # 横屏播放器 + 存读档
    ├── crop_page.dart         # 16:9 裁切页
    ├── stage_view.dart        # 四点位舞台（编辑器与播放器共用）
    └── widgets.dart           # 通用卡片 / 缩略图 / 弹窗
```

设计上把「舞台渲染」抽成 `StageView`，编辑器和播放器共用同一套点位和缩放规则，所以所见即所得；素材只存一份，多个节点可以复用。

## 5. 性能取舍

- 背景 1280×720 JPEG，单张通常 100–250KB；立绘最长边 1000 PNG。
- 舞台只用 `Image.file` + `BoxFit`，没有模糊、滤镜、粒子，低端 GPU 压力小。
- 打字机用 28ms 定时器逐字 `setState`，每次只重建台词区。
- 选图解码、透明边裁剪、缩放都放到 isolate，主线程只负责 UI。
- 播放器只保留 2 个 `AudioPlayer` 实例（BGM / 音效），切节点不会反复创建。
- 存档缩略图按 0.45 像素比截取，单张几十 KB。

## 6. 已知限制 / 后续可以做

- 剧情是「节点 + 跳转」结构，不是自由画布；一个节点最多 4 个分支（符合需求）。
- 每个作品固定 6 个存档位，够用且界面简单；后续可扩展成「自动存档 + 手动存档」。
- 暂不支持视频、Live2D、转场特效、条件变量（好感度等）。
- 只做了 Android；代码本身跨平台，补 iOS 需要 Xcode 和签名。
- 示例工程是代码绘制的占位美术，方便验证全链路，可以整个删掉。

## 7. 常见问题

**问：上传图片要开相册权限吗？**
不用。选图走系统文件选择器（SAF），APP 只读取你选中的那一个文件。

**问：换手机 / 备份作品怎么办？**
目前工程在 APP 私有目录里。后续可以加「导出工程 zip」；现在可以用文件管理器进入 `Android/data/com.hajibang.starcanvas/files/starcanvas` 手动拷走整个 `projects` 文件夹（Android 11+ 部分机型限制访问 `Android/data`，建议后续加导出功能）。

**问：为什么配音 / 音乐有的很大？**
mp3 / ogg / m4a 为了不掉音质原样保存；WAV 会被压成 22050Hz 单声道。想进一步减小体积，上传前先转成 128kbps 的 mp3。

**问：删除作品后空间真的会回来吗？**
会。删除时直接删掉 `<作品ID>` 整个目录，配置、素材、存档、缩略图一起清理。
